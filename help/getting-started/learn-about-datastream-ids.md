# Learn about datastream IDs

Learn how the datastream ID connects Web SDK events on your site to Adobe Brand Concierge in Adobe Experience Platform. You learn why the ID is required, how it routes data to the right sandbox and datasets, and how teams use separate datastreams for development, staging, and production.

## Who is this video for?

* Developer
* Product Manager
* Solution Consultant

## Video content

* Why the datastream ID is required for the Web SDK and Brand Concierge
* How the datastream routes events to sandboxes, datasets, schema, and identities
* Why teams use different datastreams for dev, stage, and production
