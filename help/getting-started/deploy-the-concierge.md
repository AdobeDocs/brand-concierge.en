# Deploy the concierge

Deploying Adobe Brand Concierge makes it available to real website visitors. This video describes configuring a datastream so visitor engagement is tracked, then setting up surface configuration to control which pages and domains the concierge appears on.

## Who is this video for?

* Marketers deploying a concierge to their website
* IT or web development teams providing a datastream ID and installing the script
* Teams controlling where the concierge appears across their site

## Video content

* Where to find the datastream ID in Adobe Experience Platform under Data Collection > Data Streams
* How to add the datastream configuration and copy the resulting install script
* Component install compared to full-page install options for the script
* How to configure surface rules by matching domains and paths (any, starts with, ends with, equals)
