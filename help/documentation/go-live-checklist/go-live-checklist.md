# Go-live checklist for a concierge

Use this checklist to complete a pre-launch readiness review before making a concierge available to real visitors. The checklist consolidates the readiness criteria described in the knowledge sources, concierge management, evaluation, and deployment workflows.

>[!NOTE]
>
>Consider publishing this checklist as a standalone page. A standalone page can be linked directly from launch communications and referenced independently of the full documentation set.

## How to use this checklist

Complete each item before launch, and record the owner or evidence for any item that requires follow-up. Do not proceed to go-live with unresolved issues unless the appropriate product, quality, or launch owner has reviewed and accepted the risk.

## Content and configuration

- [ ] **Knowledge sources are fully processed.** Confirm that all configured knowledge sources have completed processing and that no unresolved errors remain in **Fix Issues**.
- [ ] **Brand expression and brand profile are accurate.** Review the concierge's brand expression and brand profile for accuracy and alignment with the intended experience.
- [ ] **Instructions and guardrails are approved.** Review the concierge instructions and guardrails against applicable brand guidelines.
- [ ] **Skills and integrations are mapped correctly.** Confirm that all required skills are activated and correctly mapped to their integrations.
- [ ] **Visual style and chat components are approved.** Review the visual style and chat components against brand expectations.

## Testing and evaluation

- [ ] **Evaluation sets have been created and run.** Create and run at least one evaluation set for each evaluation type:
  - Functional
  - Out of scope
  - Safeguard
- [ ] **Flagged results have been reviewed.** Investigate and address flagged evaluation results before launch.
- [ ] **Live-preview testing is complete.** Test the concierge in the live preview using representative visitor questions.

## Deployment readiness

- [ ] **The datastream ID is configured.** Confirm that the correct datastream ID is configured for the deployment.
- [ ] **Surface configuration is reviewed.** Verify that the concierge will appear only on the intended pages.
- [ ] **The installation script is installed.** Provide the installation script to the website team and confirm that it has been installed successfully.
- [ ] **B2B availability is confirmed, when applicable.** For B2B concierges, confirm that the sales representative calendar and live chat availability are configured and operational.

## Post-launch readiness

- [ ] **Analytics access is confirmed.** Verify that the relevant stakeholders can access the required analytics.
- [ ] **A review cadence is established.** Establish a recurring process for reviewing conversation transcripts and adding new evaluation questions as they surface.

## Before you publish this checklist as a release requirement

>[!IMPORTANT]
>
>This checklist is derived from the workflows described in the guide. It is not an official, product-defined release gate. Validate it against Product- and QA-defined release criteria before publishing it as a formal go-live requirement.
