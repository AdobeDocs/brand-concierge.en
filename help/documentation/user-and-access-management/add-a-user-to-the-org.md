# Add a user to the organization

Before a user can access Brand Concierge, add the user to the Adobe Experience Platform organization in the Adobe Admin Console.

## Prerequisites

* You must have administrator access to the organization.
* The user must be available to add individually or through a bulk user upload.

## Add a user

1. Go to the **Admin Console**.
2. Select **Manage** or go to **Users**.
3. Add users individually, or add multiple users through a bulk upload.
4. If the user does not already exist in the organization, select the option to add the user as a new user when prompted.
5. Select the product profile:

   * **Adobe Experience Platform**
   * The default user profile

6. Select **Save**.

The user receives an email invitation confirming access to the organization.

>[!IMPORTANT]
>
>The organization invitation gives the user access to the organization, but it does not grant access to Brand Concierge. To provide Brand Concierge access, create and assign a role with the Brand Concierge permission as described in 'Create a role with Brand Concierge permission' (LINK).

## Next steps

After the user has been added to the organization, create a role with the **Manage Brand Concierge** permission and assign the user to that role.
