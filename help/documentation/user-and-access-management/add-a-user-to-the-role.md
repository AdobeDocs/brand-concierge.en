# Add users to the Brand Concierge role

Assign users to the role that contains the **Manage Brand Concierge** permission. Users must also have access to the Adobe Experience Platform organization before they can use Brand Concierge.

## Prerequisites

* The user has been added to the Adobe Experience Platform organization. For more information, see 'Add a user to the organization' (LINK).
* A role containing the **Manage Brand Concierge** permission has been created. For more information, see 'Create a role with Brand Concierge permission' (LINK).

## Add users from the role

1. In Adobe Experience Platform, open **Permissions**.
2. Open the role that was created for Brand Concierge access.
3. Select the **Users** tab.
4. Search for the user and add the user to the role.
5. Save the assignment if prompted.

## Add a role from a user record

You can also assign the role from the user's record:

1. Open the user's record.
2. Select **Add Role**.
3. Search for the Brand Concierge role.
4. Select the role and save the assignment.

## Verify access

After both the organization invitation and role assignment are complete, the user can:

* Sign in to `experienceplatform.adobe.com`.
* View the organizations they can access.
* Open **Brand Concierge**.
* View the sandbox or sandboxes granted through the role.

Within a sandbox, the user can create multiple concierges.
