# Current release information {#current-release-notes}

Adobe Brand Concierge follows a continuous delivery model, allowing Adobe to deliver new capabilities, enhancements, and fixes on an ongoing basis.

All features are generally available unless indicated otherwise.

## April 2026 {#april-2026}

* **Brand Concierge Integration with Real-Time CDP (Limited Availability)**: Enhance the quality and relevance of conversational responses by incorporating Real-Time CDP context, such as user attributes, behavioral signals, and prior interactions to better align replies with user intent.

* **Self-Serve Tuning Enhancement**: Brand Concierge Composer automatically evaluates conversation performance and updates prompt configurations to improve response quality. These optimizations are continuously applied based on automated evaluation results, reducing the need for manual tuning.

* **Context-Aware Product Recommendation**: Brand Concierge delivers product recommendations based on inferred user intent, leveraging structured product catalog data and the ability to integrate with product search and recommendation systems of record to improve relevance and accuracy. Product cards are presented when appropriate, supporting multi-product recommendations and aligning with discovery or purchase intent.

* **Side-by-Side Comparison**: Enable side-by-side comparison of multiple products within the conversation through a structured table view, highlighting key attributes, features, and differences. The comparison is dynamically generated based on user intent and selected products, supporting more informed evaluation and decision-making.

* **Support Agent (Troubleshooting and How-To Guidance)**: Enable guided support within the conversation by helping users troubleshoot issues and complete how-to tasks through context-aware assistance. The agent adapts responses based on user input to drive efficient issue resolution without requiring escalation.

## March 2026 {#march-2026}

* **Site Advisor AEM Configuration in Composer**: Site Advisor AEM Configuration in Composer enables AEM customers to easily set up knowledge source ingestion directly in Composer, with AEM website content as the primary knowledge source. This reduces onboarding friction while ensuring accurate, compliant, and predictable responses grounded in the customer's own AEM content.

* **Full-Site Ingestion**: Full-Site Ingestion enables customers to automatically ingest their entire website using a single sitemap, eliminating the need for manual URL uploads. This ensures complete, up-to-date content coverage with scalable, low-effort onboarding and ongoing content freshness.

* **Automated Prompt Creation (Limited Availability)**: Automated Prompt Creation lets customers create a high-quality Brand Concierge experience through a simple, self-serve flow. Brand Concierge automatically generates concierge prompts from minimal user inputs without exposing or requiring prompt engineering. Non-technical users can quickly get a working, quality-validated concierge through guided brand profile validation and AI-driven configuration.

* **BYOA - Firefly Agent in Adobe.com Brand Concierge**: Firefly image generation is now integrated into Adobe.com Brand Concierge, enabling users to create, download, and continue editing images or moodboards in Firefly. This is our first launch of the "Bring Your Own Agent" integration, enabling customer and third-party agents within Brand Concierge via the Agent Orchestrator.

## February 2026 {#february-2026}

* **Automated Eval Dataset Generation**: Automatically generate high‑quality evaluation datasets for functional, out-of-scope, and safeguard evaluations. The eval dataset is grounded directly in the brand's knowledge base, ensuring reliable, high‑confidence testing.

* **Automated Evaluation & LLM-Based Quality Loop**: Validate Concierge performance with one click using LLM-based scoring across quality dimensions including correctness, helpfulness, and brand adherence. This delivers objective, repeatable quality assessments that give customers confidence before every launch.

* **Automation for Concierge Creation & Launch Tasks (Developer UI)**: This is an internal, developer-facing feature that enables teams to spin up and launch a Concierge experience quickly, with options to manage sandbox and Concierge config, UI/styling config, and prompt tuning. This accelerates time to go-live and empowers teams to create customized, high‑quality Concierge instances at scale.

* **Knowledge Source Enhancement: Incremental URL Upload/Refresh and Additional File Type Support**: The incremental URL management feature allows customers to easily update (add/delete/refresh) only the pages that have changed, without reprocessing the entire knowledge source. This reduces update time and lowers operational overhead. In addition, Brand Concierge now supports PDF/DOCX file upload.

* **Custom Product Schema Support**: The custom schema support feature allows customers to upload and manage product catalogs that follow their own data structure rather than a fixed format. This enables proper validation, field mapping, and accurate product card generation across brands with differing catalog models.

* **Mobile SDK**: The Brand Concierge Mobile SDK (for mobile apps) enables brands to embed Brand Concierge directly into their mobile apps, supporting text, voice, and image interactions. It provides an out‑of‑the‑box interface and backend integration so consumers can easily access Brand Concierge within the brand's app.
